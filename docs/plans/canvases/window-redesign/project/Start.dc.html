worktree-sweep — ▢ ✕

Choose a folder to sweep

worktree-sweep looks at the folder's top-level repos and at their worktree folders (*.wt, *-wt, *worktrees, .claude\worktrees). The scan only reads; nothing is removed until you review and confirm.

Starts in the folder you launched from. Passing a folder on the command line skips this step: worktree-sweep X:\dev
